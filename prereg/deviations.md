# Deviations from the pre-registration

`preregistration.md` stays as frozen. Every change is recorded here with its date and whether it
was made before or after any result was seen. "Results" means any regression involving returns.

| ID | Date | Prereg § | Change | Before/after results | Reason |
|---|---|---|---|---|---|
| D1 | 2026-09-27 | 3.2 | **Weather sources.** NYC: NOAA GHCNh hourly, LaGuardia USW00014732 (1948+), with JFK USW00094789 filling hours LaGuardia lacks. This replaces ISD-Lite LaGuardia → Central Park → JFK. Sydney: ISD-Lite 947670 as planned, with IEM METAR YSSY filling missing hours (2000+) and the period after ISD-Lite ends. Total sky cover = the highest reported layer coverage in oktas. METAR categories map to FEW = 2, SCT = 4, BKN = 6 (Sydney/IEM, matching ISD-Lite) or 7 (NYC/GHCNh coding), OVC = 8. Obscured (VV) is missing. | Before | NOAA froze ISD-Lite in Aug 2025 (no 2026 files), and its LaGuardia record starts only in 1973. GHCNh is NOAA's successor product built from the same reports and has LaGuardia back to 1948. GHCNh has no Sydney sky cover. On 6,052 overlapping days, ISD and IEM daily cloud correlate at 0.93. The level difference between codings is absorbed by per-city standardised anomalies, and robustness checks use ERA5 (one source for both cities). |
| D2 | 2026-09-27 | 3.2 | **Minimum valid hours per day:** 3 instead of 4. | Before | Sydney 1974–1999 reports every 3 hours. During daylight saving, the 06:00–16:00 window then contains only 3 reports, so a 4-report rule drops about 40% of Sydney days in a seasonal pattern (summer only). That would bias both the sample and the SAD tests. NYC coverage is the same under either rule. |
| D3 | 2026-09-27 | 3.1 | **AU dividend add-back.** RBA table F7 no longer contains share-market dividend yields (F7 is now business lending rates). The add-back is now the average daily dividend return in each calendar month, taken from log return(^AXJT) − log return(^AXJO) over 2019-05 → 2026 (daily differences above 1% in absolute value are dropped as artefacts) and applied to every year. Daily ^AXJT − ^AXJO is not used directly because it contains stale-price artefacts (paired ±0.4–0.8% swings on consecutive days) and a +2.2% glitch on 2019-10-04. Price-only AU returns are reported as robustness. | Before | The original source no longer exists, and Yahoo's ^AXJT total-return index starts only in 2019. Deseasonalised weather anomalies are nearly orthogonal to a calendar-month profile, so this matters mainly for H3. |
| D4 | 2026-09-27 | 5, 6 | **H3 decision rule.** H3 is judged on the Holm-adjusted HAC test alone. The placebo criterion does not apply because §6 defines placebos only for CLOUD and TEMP, and SAD/FALL are deterministic astronomical functions of latitude and date (they have no "placebo city" or "year-shifted" version). | Before | Fixes a gap in the pre-registration: the decision rule in §5 needs a placebo percentile, but §6 defines none for H3. |
| D5 | 2026-09-27 | 6 | **ERA5 source for placebo cities:** the Copernicus CDS point time series (`reanalysis-era5-single-levels-timeseries`, total cloud cover and 2 m temperature) instead of the Open-Meteo archive API. All 104 cities (100 placebos plus NYC, SYD, MEL, CHI) come from CDS so the data are consistent. Open-Meteo is used only if CDS is unavailable. | Before placebo results | Open-Meteo's free quota allows about 18 full-history cities per day, so the fetch would take about 6 days. CDS serves the same ERA5 reanalysis with no quota. |
